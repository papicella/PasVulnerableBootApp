Run your Spring Boot app, then:

Vulnerable: http://localhost:8080/vuln/xss?input=<script>alert('xss')</script> → the script will execute.
Safe: http://localhost:8080/vuln/xss-safe?input=<script>alert('xss')</script> → the script will be shown as text (escaped), not executed.

Build image with docker:

$ docker build --tag=pasvulnerablebootapp:latest .
$ docker tag pasvulnerablebootapp:latest pasapples/pasvulnerablebootapp:latest
$ docker push pasapples/pasvulnerablebootapp:latest

View image layers:

$ dive pasapples/pasvulnerablebootapp:latest
$ docker image inspect pasapples/pasvulnerablebootapp:latest --format="{{range .RootFS.Layers}}{{.}}{{println}}{{end}}"
